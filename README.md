Analizador Inteligente de Tráfico de Red mediante Machine Learning

Descripción

Este proyecto tiene como objetivo desarrollar una herramienta para el análisis del tráfico de red y la detección de comportamientos anómalos mediante técnicas de Machine Learning.

La aplicación utiliza Python, PyShark y Streamlit para procesar capturas de paquetes, analizar las comunicaciones y visualizar los resultados.

Se propone incorporar un modelo de aprendizaje automático que permita identificar patrones de tráfico que se aparten del comportamiento habitual de una red.

Antecedentes

El proyecto toma como base el trabajo «Analizador de paquetes e interfaces de redes con PyShark y Streamlit», presentado en las 53 JAIIO por Gastón Alejandro Escalante, Leopoldo Rios y Rodrigo Zalazar.

Repositorio original: https://github.com/gaston411/analizador_pyshark

El presente desarrollo constituye una ampliación académica del analizador original, realizada con autorización de sus autores.

Funcionalidades actuales

Identificación de interfaces de red.

Captura de paquetes mediante PyShark.

Procesamiento de archivos PCAP y PCAPNG.

Exportación de información a CSV.

Análisis del tráfico por direcciones IP y protocolos.

Visualización de gráficos del tráfico de red.

Funcionalidades previstas

Extracción de características del tráfico de red.

Detección de anomalías mediante Machine Learning.

Identificación de comportamientos inusuales en las comunicaciones.

Visualización de anomalías y generación de alertas.

Evaluación del modelo mediante escenarios de prueba.

Exportación de resultados.

Objetivo general

Desarrollar una herramienta de análisis inteligente del tráfico de red que permita identificar comportamientos anómalos mediante técnicas de Machine Learning, facilitando la interpretación y visualización de las comunicaciones.
